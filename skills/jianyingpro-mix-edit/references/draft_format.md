# 剪映 Draft File Format — Internals Reference

Read this only if you need to customize beyond what `build_draft.py` exposes (e.g. add transitions, captions, keyframes by hand-editing the JSON). For routine use, the script is enough.

## Folder layout

```
~/Movies/JianyingPro/User Data/Projects/com.lveditor.draft/<name>/
├── draft_content.json          # Timeline truth — REQUIRED, written by us.
├── draft_meta_info.json        # Sidebar metadata — REQUIRED, written by us (剪映 fills missing fields on first scan).
├── draft_cover.jpg             # Optional thumbnail. Don't write a fake one — invalid JPEG breaks the list.
├── draft_virtual_store.json    # Auto-generated by 剪映.
├── draft_biz_config.json       # Auto-generated.
├── attachment_pc_common.json   # Auto-generated.
└── template-2.json / template-3.json   # Auto-generated.
```

(The "settable via 全局设置 → 草稿位置" path overrides the default directory.)

## Time conventions

- All durations and offsets are **microseconds** (`1 s = 1_000_000`). No frame-based timing.
- Top-level `duration` must equal `max(segment.target_timerange.start + segment.target_timerange.duration)` across all tracks. Setting it shorter truncates the timeline silhouette.
- `fps` is metadata only.

## `draft_content.json` skeleton

```jsonc
{
  "id": "<UUID>",
  "canvas_config": {"width": 1920, "height": 1080, "ratio": "original"},
  "fps": 30.0,
  "duration": 0,                // overall project length, microseconds
  "version": 360000,
  "new_version": "110.0.0",
  "platform": {"app_id": 3704, "app_source": "lv", "app_version": "5.9.0", "os": "mac"},
  "last_modified_platform": {/* same */},
  "config": { /* large static block — copy from pyJianYingDraft template */ },
  "keyframes": {"audios": [], "videos": [], "texts": [], /* … */},
  "materials": {
    "videos": [],
    "audios": [],
    "texts": [],
    /* ~40 more empty arrays — ALL keys must exist or 剪映 may drop the draft */
  },
  "tracks": [],
  "color_space": 0,
  "source": "default",
  "relationships": []
}
```

`pyJianYingDraft` ships these skeletons; we never craft them by hand.

## `materials.videos[i]` (also for `kind: photo`)

```jsonc
{
  "id": "<uuid hex>",
  "material_id": "<same>",
  "type": "video",                // or "photo" for stills
  "path": "/abs/path",
  "material_name": "clip01.mp4",
  "duration": 5000000,            // microseconds (stills use 10800000000 sentinel = 3h)
  "width": 1920, "height": 1080,
  "crop": { /* 8 corner floats, defaults */ },
  "crop_ratio": "free",
  "crop_scale": 1.0,
  "category_name": "local",
  "check_flag": 63487,
  "local_material_id": "",
  "media_path": ""
}
```

Stills (`type: photo`) use the 3-hour sentinel for `duration`; the segment's `target_timerange` controls actual on-screen time.

## Segments

Video segment:

```jsonc
{
  "id": "<uuid>",
  "material_id": "<video material uuid>",
  "source_timerange": {"start": 0, "duration": 5000000},      // range INTO source
  "target_timerange": {"start": 0, "duration": 5000000},      // range ON track
  "speed": 1.0,
  "volume": 1.0,
  "render_index": 0,
  "extra_material_refs": [],   // REQUIRED, even empty
  "visible": true,
  "reverse": false,
  "track_attribute": 0,
  "track_render_index": 0,
  "enable_adjust": true,
  "enable_lut": true,
  "enable_color_curves": true,
  "common_keyframes": [],      // REQUIRED, even empty
  "keyframe_refs": [],         // REQUIRED, even empty
  "last_nonzero_volume": 1.0,
  "clip": {
    "alpha": 1.0,
    "scale": {"x": 1.0, "y": 1.0},
    "transform": {"x": 0.0, "y": 0.0},
    "rotation": 0.0,
    "flip": {"horizontal": false, "vertical": false}
  }
}
```

Audio segment: same shape, no `clip` block, `volume` is the lever.

## `draft_meta_info.json`

Required fields (the rest follow pyJianYingDraft's template verbatim):

| Field               | Type              | Notes |
|---------------------|-------------------|-------|
| `draft_id`          | string            | New uppercase UUID with hyphens (e.g. `BC69C7CD-1234-…`). |
| `draft_name`        | string            | Match the folder name. |
| `draft_fold_path`   | string            | Absolute path to the draft folder. |
| `draft_root_path`   | string            | Parent (`…/com.lveditor.draft`). |
| `tm_draft_create`   | int               | Microseconds since epoch (`int(time.time() * 1e6)`). |
| `tm_draft_modified` | int               | Same. |
| `tm_duration`       | int               | Total project duration (µs). |
| `draft_cover`       | string            | `"draft_cover.jpg"` if you write one, else `""`. |
| `draft_materials`   | array of 7 typed buckets | Types `0,1,2,3,6,7,8`. Empty `value: []` is fine; missing the list has been reported to break 剪映's draft list. |

## Hard-learned gotchas

- **Every key in `materials` must exist** even as `[]`. Missing keys cause silent "draft disappears from list" or load-time crash.
- **`extra_material_refs` / `common_keyframes` / `keyframe_refs` are mandatory** on segments. Empty arrays are fine; omitted fields are not.
- **Absolute paths**, including for media. 剪映 does not resolve relative.
- **UTF-8 with `ensure_ascii=False`** — Chinese filenames work fine if encoded right.
- **6.x-encrypted drafts** (drafts that 剪映 6.x has saved) cannot be re-read by tools. We always write fresh, unencrypted drafts, so this only affects round-tripping.
- **Top-level `duration`** must equal the longest `target_timerange.end`; otherwise the timeline visual is truncated.
- **Don't fabricate `draft_cover.jpg`** — an invalid JPEG is worse than no cover.
- **macOS sandbox / TCC**: media outside `~/Movies` triggers a Files-and-Folders prompt on first open. Copy media into the draft folder for a frictionless first open.
