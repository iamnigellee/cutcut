# 剪映混剪 Skill 使用指南

写给使用这个 Skill 的人。覆盖：第一次怎么装、日常怎么用、跟 AI 怎么说能让它做对事、出问题怎么调。

---

## 这个 Skill 帮你做什么

把这件事想成"AI 出脑子 + 剪映做精修"的流水线：

| 谁做 | 做什么 |
|---|---|
| **AI（这个 Skill）** | 拼接素材、TTS 配音、自动加音效、生成剪映草稿 |
| **你** | 提供素材 + 文案；最后在剪映里调转场、调色、加 BGM、导出 |

**AI 不做**：BGM（剪映自带音乐库更顺手）、转场特效、字幕样式、调色、导出。这些都在剪映里手动完成。

---

## 第一次使用（一次性，5 分钟）

```bash
# 1. 拉代码
git clone https://github.com/iamnigellee/cutcut ~/code/cutcut

# 2. 接入到 Claude 客户端
mkdir -p ~/.claude/skills
ln -s ~/code/cutcut/skills/jianyingpro-mix-edit ~/.claude/skills/jianyingpro-mix-edit

# 3. 装依赖
brew install ffmpeg
python3 -m pip install --user -r ~/.claude/skills/jianyingpro-mix-edit/scripts/requirements.txt
```

重启客户端。第一次说"用剪映把这些素材混剪一下"，Skill 会自动触发；如果没触发，看[导入排查](#导入失败排查)。

## 两种使用场景

| | 场景 | 你手上有 |
|---|---|---|
| **Mode A** | 我有素材，写好了配音稿，AI 帮我配音+加音效+拼起来 | 视频/图片 + 配音稿 `.txt` |
| **Mode B** | 我只有文案稿和一堆原始素材，AI 帮我决定哪段素材配哪句话 | 文案稿 `.txt` + 素材文件夹 |

下面分别给完整流程和对话示例。

---

## Mode A — 已有素材 + 配音稿

### 起手怎么说

最低限度的指令——AI 会自己来问缺的：

```
帮我做个混剪。
素材在 ~/Videos/shenzhenwan/，按文件名顺序拼。
文案在 ~/Documents/script.txt。
```

更省事的完整版：

```
帮我做个混剪：
- 素材：~/Videos/clip_01.mp4 / clip_02.mp4 / clip_03.mp4 顺序拼
- 文案：~/Documents/script.txt
- 音色：沉稳一点，纪录片那种
- 画面：竖屏 1080x1920
- 音效：中等密度
- 草稿名：shenzhenwan_vlog
```

### AI 会问什么

如果起手指令信息不全，AI 会问类似：
- "音色你想要男声还是女声？沉稳还是轻快？" → 答风格描述就行，AI 会翻成具体音色 ID
- "画布要 16:9 横屏还是 9:16 竖屏？" → 看你发哪个平台
- "音效密度：少（每 10 秒 1 个）/ 中（每 5 秒）/ 多（每 3 秒）？" → 默认中
- "草稿名叫什么？" → 随便起，会成为剪映里看到的名字

**省时建议**：起手指令里就一次性给齐，能省 2-3 轮来回。

### AI 会做什么（你能看到的）

1. 跑 TTS，告诉你"配音 32.5 秒"
2. 列出每段素材的时长，告诉你"9 段素材总长 45 秒，比配音长 12.5 秒"——这时候 AI 会问要不要 trim 某些素材，或者保留尾部静默
3. 列出"我打算在 1.84s 加 whoosh、5.20s 加 ding..."的音效计划，让你确认
4. 生成草稿 + 自动开剪映
5. 报告草稿名和路径

### 你看到结果后做什么

剪映打开后，**新草稿在草稿列表最上面**。点进去：

1. 先听一遍配音 + 音效，找到要调的地方
2. 加 BGM：剪映顶栏 → 音频 → 音乐 → 选一首拖到时间线
3. 加转场：时间线两段视频中间的小白点 → 选转场类型
4. 改字幕：剪映顶栏 → 文本 → 智能字幕（或者导入 `/tmp/vo_out/vo.srt`）
5. 调色 / 加滤镜 / 加贴纸 → 都在右侧面板
6. 导出：右上角"导出"按钮

## Mode B — 文案稿 → 整片

### 起手怎么说

```
我有一份文案稿和一堆原始素材，帮我做整版混剪。
文案：~/Documents/script.txt
素材文件夹：~/Videos/raw_footage/
风格：轻快 vlog
```

### AI 会做什么（关键不同点）

Mode B 比 Mode A 多了**素材分镜**这一步：

1. **TTS 配音稿** → 拿到每句话的开始/结束时间
2. **扫素材文件夹** → 列出每个文件的时长、宽高、文件名
3. **AI 提议分镜表**给你看：

```
句 1 (0.0–2.4s, "今天我们来到深圳湾...")  → 03_skyline_pan.mp4 (用整段)
句 2 (2.4–5.1s, "天气特别好...")         → 07_blue_sky.mp4 (取 0–2.7s)
句 3 (5.1–8.3s, "海风迎面吹来...")       → 09_seabreeze.mp4 + 11_waves.mp4 (各 1.6s)
```

4. **你确认或改**——这一步**一定要你看一眼**，AI 会按文件名猜，可能猜错
5. 加音效、生成草稿、开剪映

### 让 AI 猜得准的素材命名建议

文件名描述性越强，AI 分镜越准：

| 不好 | 较好 | 最好 |
|---|---|---|
| `IMG_0023.mp4` | `clip_03.mp4` | `03_海风_海浪特写.mp4` |
| `DJI_0017.mp4` | `aerial_2.mp4` | `02_航拍_深圳湾大桥.mp4` |

如果文件名都是 `IMG_xxxx`，AI 会让你给每个文件一句话简介。**别嫌烦**，提前花 2 分钟标注比事后改 spec 快得多。

## 给 AI 发指令的话术模板

### 起手类

| 想要 | 说法示例 |
|---|---|
| 最简单 | `帮我把 ~/Videos 里的视频混剪一下，文案在 ~/script.txt` |
| 指定风格 | `做个轻快 vlog 风格的混剪，男声，竖屏` |
| 指定音效密度 | `音效给我加多一点，每 3 秒一个左右` |
| 不要音效 | `这次不要加音效，只配音 + 拼接就行` |
| 指定草稿名 | `草稿名叫 shenzhenwan_20260427` |

### 改音色

| 想要 | 说法示例 |
|---|---|
| 换男女 | `配音换成女声` |
| 换风格 | `音色再沉稳一点，像央视纪录片那种` |
| 换语速 | `语速放慢 10%` |
| 指定 ID | `用 zh-CN-XiaoxiaoNeural 重做配音` |
| 有具体感觉 | `这段太平了，第二句话情绪激动一点` |

### 改音效

| 想要 | 说法示例 |
|---|---|
| 减少 | `音效太多了，减一半` |
| 加多 | `音效再多点，特别是开头` |
| 换种类 | `所有 ding 换成 boing，我想要更搞笑的感觉` |
| 删某个 | `把第三个 whoosh 去掉` |
| 换位置 | `开头那个 whoosh 挪到 0.5 秒` |
| 调音量 | `音效声音都太大了，统一降到 0.3` |

### 改素材（Mode B 常用）

| 想要 | 说法示例 |
|---|---|
| 换某句对应的素材 | `第 3 句应该用 09_seabreeze 不是 11_waves` |
| 重新分镜 | `分镜重做，按"近景 → 中景 → 远景"的节奏` |
| 加素材 | `这段我有新素材 ~/Videos/extra.mp4，插在第 5 句` |
| 删素材 | `不要用 clip_07.mp4` |
| 改顺序 | `clip_05 和 clip_03 顺序对调` |

### 改文案

| 想要 | 说法示例 |
|---|---|
| 小改 | `第二句改成"天气棒极了"，重做配音那一步就行` |
| 大改 | `文案我重写了在 ~/script_v2.txt，整个重做一遍` |

### 微调画面

| 想要 | 说法示例 |
|---|---|
| 改画布 | `改成竖屏 1080x1920` |
| 改 FPS | `改成 60 帧` |
| 改长度 | `第二段视频太长了，trim 到 5 秒` |

### 重做某一步

AI 默认会**最小重跑**——你说改音效它不会重跑 TTS。但如果你想强制：

| 想要 | 说法示例 |
|---|---|
| 只重做音效 | `音效重做就好，配音不用动` |
| 全部重做 | `从头重新生成一遍` |
| 只重开剪映 | `重新打开一下剪映，新草稿没刷出来` |

## 输入准备的小建议

### 文案稿怎么写更准

`script.txt` 直接放纯文本，**用句号/问号/感叹号断句**——TTS 用这些来确定停顿：

```
今天我们来到深圳湾。天气特别好，海风迎面吹来。这片海，就是我童年的味道。
```

避免：

- ❌ 一整段没标点 → TTS 会喘不过气
- ❌ 嵌入英文长句而音色是 `zh-CN-*` → 会被音译，发音怪
- ❌ 数字写阿拉伯 "$3.14" → 念成"美元三点一四"，读 "三点一四美元" 更稳的话直接写中文

混合中英：

```
我们用 [英文] React Native [/英文] 做了 demo。
```

需要的话告诉 AI："文案里 React Native 不要音译"，它会用 SSML 切语言。

### 素材怎么放

最省事：**一个文件夹，文件名带顺序前缀**

```
~/Videos/shenzhenwan/
├── 01_海岸航拍.mp4
├── 02_海风特写.mp4
├── 03_海浪.mp4
└── 04_夕阳.mp4
```

混合视频和照片也行，照片默认在画面停 3 秒。

### 画布怎么选

| 用途 | 画布 |
|---|---|
| 抖音 / 快手 / 视频号 / 小红书 | 1080×1920（9:16 竖屏） |
| B 站 / YouTube / 横屏播放 | 1920×1080（16:9） |
| 朋友圈 / Instagram 单图风 | 1080×1080（1:1） |
| 4K 拍摄 + 高质量交付 | 3840×2160 |

**素材分辨率不一致**没关系，AI 不会自动裁剪；剪映里手动调每段的"缩放"或"画面"就行。

## 微调与迭代

典型的迭代节奏是这样的：

```
轮 1：起手指令 → AI 全跑一遍 → 你听 demo
轮 2："音色太硬，换成温柔点的女声" → AI 只重跑 TTS + 重生成草稿
轮 3："第三段素材换成另一个" → AI 只改 spec.json + 重生成
轮 4：在剪映里手动调转场和 BGM → 导出
```

**省 token 小技巧**：

- 改音效不需要重跑 TTS——明确说"只重做音效"
- 改素材顺序不需要重跑 TTS——明确说"配音保留，重新拼素材"
- 改文案必须重跑 TTS——这步免不了

## 你必须自己做的事

| 事 | 在哪做 |
|---|---|
| 加 BGM | 剪映 → 音频 → 音乐 |
| 加掌声/笑声/雨声等真实音效 | 剪映 → 音频 → 音效（自带库） |
| 加转场 | 剪映时间线两段视频中间 |
| 加字幕样式 | 剪映 → 文本（或导入 `vo.srt`） |
| 调色 / 加滤镜 / 加贴纸 | 剪映右侧面板 |
| 导出 | 剪映 → 右上角导出 |

**为什么 BGM 不让 AI 做**：版权问题难绕过、链接易失效、剪映自带库已经够好。

**为什么导出不让 AI 做**：剪映在 macOS 上禁用了第三方草稿的命令行导出，这是上游限制。

## 出问题怎么办

### 导入失败排查

| 报错 | 怎么办 |
|---|---|
| `description too long` / 类似超长 | 已修，确保你拉了最新 commit |
| `unknown field: license` 或 `version` | 已修（移除非标准字段），拉最新 |
| `skill not found` | 检查 `~/.claude/skills/jianyingpro-mix-edit/SKILL.md` 路径正确 |
| 客户端要求扁平结构 | 不放符号链接，直接拷贝 SKILL.md 到 `~/.claude/skills/`（备选方案） |

### 跑起来出错

具体错误对照 `references/troubleshooting.md`，常见的：

| 现象 | 最可能原因 |
|---|---|
| 剪映里看不到新草稿 | 剪映缓存了草稿列表 → 重启剪映 |
| 剪映打开草稿"无法读取媒体" | 文件路径错 / quarantine xattr / 没给剪映文件夹权限 |
| `pyJianYingDraft not installed` | `python3 -m pip install --user pyJianYingDraft` |
| `edge-tts` 卡住 | 没网，edge-tts 需要连 Microsoft 的 endpoint |
| 音效声音不对 | 编辑 `assets/sfx_manifest.json` 里的 ffmpeg recipe，跑 `generate_sfx.py --force` |
| 配音和音效错位 | 语速太快导致 word-boundary 不准；进剪映里手动挪音效是最快的 |

## 一句话总结

**给 AI 起手指令越具体，迭代越少。在剪映里精修是必经之路，AI 只负责让你少做 80% 的拼接劳动。**
